# WATCHLIST — dated events the Federal Register cannot know about.
#
# The brief counts down to every line here, every morning, until the date
# passes. Then it disappears on its own; there is nothing to clean up.
#
# ONE EVENT PER LINE, fields separated by | . The first three are required
# and the rest are optional, so a short line is still a valid line:
#
#   date | tag | what happens | source link | last checked | class | lead
#   ----   ---   ------------   -----------   ------------   -----   ----
#   YYYY-MM-DD                  optional      see below      opt.    opt.
#
# Example:
#   2026-09-29 | tariff | Pharma tariff takes effect | https://x.com/y | 2026-09-05
#
# CLASS decides how quickly an entry goes "unconfirmed" (see below):
#   policy     75 days   the default. Summits, FOMC, tariffs, announcements
#   statutory  365 days  fixed in law. It cannot move
#   holiday    365 days  announced annually, then fixed
#   unlock      30 days  reserved; no free source, so nothing uses it yet
#
# LEAD is how many days before the date it starts appearing, so a year-long
# horizon does not flood the section. Leave it blank to show it the whole way
# out. Rough guide: a summit or election 60, an FOMC 21, an expiry 14, a
# holiday 7.
#
# Tags are free text and only used for grouping. Useful ones: tariff, fed,
# geopolitics, election, court, energy, crypto, earnings.
#
# ABOUT "LAST CHECKED". An entry nobody has re-checked within its class's
# horizon gets marked "unconfirmed" in the brief rather than trusted. That is deliberate: dates
# announced by press conference move all the time, and a stale line that looks
# confident is how a wrong date ends up in front of a position. When you
# confirm an entry still stands, change that date to today.
#
# Lines starting with # are ignored. Blank lines are ignored. A malformed line
# is skipped and reported at the bottom of the brief, so nothing fails
# silently.
